クラドニ図形シミュレーター
音で砂が模様になる

黒い板の上に、砂を数千つぶまきました。板がふるえると、砂はふるえの大きい所ではねて、ふるえない場所（節）に集まり、線の模様をつくります。m と n を変えると、砂がサーッと動いて別の模様に変わります。

板をタップ（クリック）すると、そこに砂をまけます。

音は、ボタンをおしたときだけ小さめに鳴ります。もう一度おすと止まり、15秒たつと自動で止まります。音の高さは模式的な値です。

このシミュレーターのしくみ

板のふるえ方は、正方形の板でよく使われる次の近似式で決めています（x・y は板の上の位置で、どちらも 0〜1）。

ふるえの大きさ ＝ cos(nπx)·cos(mπy) − cos(mπx)·cos(nπy)

まん中の符号を ＋ にしたものが「＋の型」です。この値が 0 になる場所が節（ふし）で、板がふるえていてもそこだけは動きません。

砂は、次のかんたんな規則で動かしています。

  • 砂つぶは1つぶずつ、1秒間に60回、でたらめな向きにはねます。
  • はねる大きさは、その場所のふるえの大きさに比例します。ふるえが大きい所ほど、遠くまではねます。
  • ふるえがとても小さい所（節のすぐ近く）に入った砂は、もう動きません。止まる場所は砂つぶごとに少しずつちがうので、線に太さが出ます。

なお、模様が細かいとき（m・n が大きいとき）は、見やすいように全体のはね方を少し小さくしています。

「節のほうへ進め」という命令は入れていません。それでも、よくはねる所からは砂が出ていき、はねない所には砂がたまるので、しぜんに節の線がうかび上がります。「節に集まった砂」の数字は、ふるえの大きさがいちばん大きい所の10%より小さい場所にある砂の割合です。

ためしてみたいこと

  • m か n を1つだけ変える：できあがった模様がくずれ、砂が流れて新しい模様にまとまります。節の場所が変わると、今までの場所が「ふるえる所」になるからです。
  • m と n を大きくする：節の線がふえて、模様が細かくなります。音を鳴らしていると、音も高くなります。
  • ＋と−を切りかえる：同じ m・n でも模様が変わります。−の型では、対角線（左上から右下）にかならず砂の線ができます。
  • ふるえの強さを変える：強くすると砂が速く動き、線は細くなります。弱くすると、砂は節の少し手前で止まるので、線が太くなります。
  • 板をタップして砂をまく：ふるえの大きい所にまくと、すぐにちっていきます。節の上にまくと、そのまま動きません。
  • 「ふるえの大きさを色で見る」をおす：青く光っている所が、よくふるえている所です。砂の線が、青くない所を通っていることをたしかめられます。

本物では

ドイツの物理学者エルンスト・クラドニ（1756〜1827）は、金属の板に砂をまき、板のふちをバイオリンの弓でこすって鳴らすと、音の高さによってちがう模様ができることを調べ、1787年に本にまとめて発表しました。目に見えない音のふるえを、目で見えるようにした実験として知られています。

クラドニは1808年ごろにパリでこの実験をひろうし、それを見たナポレオンは、模様を数学で説明した人に賞を出すことにしました。この問題に取り組んだのがフランスの数学者ソフィ・ジェルマンで、1816年に賞を受けています。

今では弓のかわりに、スピーカーや振動を出す機械を板の中心に取りつけて実験することが多くなっています。弦楽器の板のふるえ方を調べるのにも、同じ方法が使われてきました。

単純にしているところ：このシミュレーターの式は近似です。ふちが自由に動ける本物の板のふるえ方はもっと複雑で、かんたんな式では書けません（20世紀のはじめにリッツが近似の計算方法を示しました）。そのため、本物の模様は線が曲がっていたり、ここで見える模様と少しちがっていたりします。砂の動かし方も、本物の砂が板の上ではねるようすをとても単純にしたものです。また、とても細かい粉は、砂とは反対に、ふるえの大きい所に集まることがあります。

よくある質問

クラドニ図形とは何ですか？
ふるえている板の上に砂などの粉をまいたときにできる模様のことです。板には、大きくふるえる場所と、ほとんどふるえない場所（節）があります。砂は節に集まるので、節の形が線の模様として見えます。ドイツの物理学者エルンスト・クラドニが18世紀の終わりにくわしく調べて発表したので、この名前がついています。
なぜ砂は線の上に集まるのですか？
ふるえの大きい所にある砂は、板にはじかれてあちこちにはねます。はねた先がふるえの小さい所だと、そこではあまりはねなくなります。これをくり返すうちに、砂はふるえない場所（節）にたまっていきます。節は点ではなく線になってつながっているので、砂の線ができます。
m と n は何を表していますか？
このシミュレーターの式の中で、板の横方向と縦方向に波がいくつ入るかを決める数です。大きくするほど節の線がふえて、模様が細かくなります。m と n を入れかえても、できる模様は同じです。
「−の型」と「＋の型」は何がちがいますか？
2つのふるえ方を引き算で重ねるか、足し算で重ねるかのちがいです。同じ m と n でも、型を変えると模様が変わります。−の型では、板の対角線（左上から右下）がかならず節になります。また、−の型で m と n を同じにすると板全体がふるえなくなるので、このシミュレーターでは自動で1つずらしています。
鳴る音は、本物の板の音と同じですか？
いいえ、同じではありません。このシミュレーターの音の高さは「m×m＋n×n に比例する」とした模式的な値で、模様が細かいほど音が高くなることを感じてもらうためのものです。本物の板の音の高さは、板の材料・厚さ・大きさ・支え方で決まります。
