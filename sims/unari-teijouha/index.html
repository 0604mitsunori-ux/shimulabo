うなりと定常波のシミュレーター（弦・気柱の固有振動）

表示を4つに切りかえて、波の重ね合わせを確かめます。①うなりでは2つの音の波形と合成波を表示し、実際の音も鳴らせます。②定常波では入射波と反射波から腹と節ができる様子を、③弦と④気柱（閉管・開管）では固有振動のようすと振動数の計算を見られます。

青＝振動数 f₁ の音、オレンジ＝f₂ の音、緑＝2つを重ね合わせた合成波。音は「🔊」ボタンを押したときだけ鳴り、10秒で自動的に止まります。

このシミュレーションでわかること

ポイント：振動数 f₁ と f₂ がわずかに異なる2つの音を重ねると、1秒間に |f₁−f₂| 回のうなりが聞こえます。逆向きに進む同じ波を重ねると定常波（定在波）ができ、隣り合う節の間隔は λ/2 です。弦の固有振動数は fₙ＝nv/2L（v＝√(S/ρ)）、閉管は f＝(2n−1)V/4L、開管は f＝nV/2L、音速は V＝331.5＋0.6t 〔m/s〕です。

高等学校「物理基礎」の「(2) 様々な物理現象とエネルギーの利用」(ｱ)波 ㋐波の性質（重ね合わせ・定在波）と ㋑音と振動（気柱の共鳴・弦の振動・うなり）で学ぶ内容です（学習指導要領 平成30年告示）。内容の取扱いには「定在波も扱い」「波の反射，共振，うなりなどを扱う」とあり、解説では、うなりの合成波の形をコンピュータで調べることや、弦の振動数と弦の質量・張力との関係を調べることが例に挙げられています。正弦波の式と位相は「物理」の (2) 波で扱います。

表示を4つに切りかえられます。①うなり：2つの音の波形と合成波を表示し、実際の音を鳴らせます。②定常波：右へ進む入射波と、端で反射して左へ進む反射波を重ね、腹と節ができる様子を見ます。③弦の固有振動：弦の長さ・張力・線密度から振動数を求めます。④気柱の固有振動：閉管と開管の空気の振動（縦波）を、粒の動きと変位のグラフで表示します。

授業での使い方

  • 導入：おんさ2本の代わりに、①うなりで 440 Hz と 444 Hz の音を鳴らし、「ウォーン、ウォーン」と大きくなる回数を数えさせます。振動数の差を変えると、うなりの速さが変わることがすぐにわかります（音はボタンを押したときだけ鳴り、10秒で止まります。最初は音量を小さくしてください）。
  • 展開：②定常波で「1/8周期すすめる」を押しながら、入射波と反射波の重ね合わせをノートに作図させ、画面と答え合わせをします。固定端と自由端で、端が節になるか腹になるかを比べます。③弦では、張力を4倍にすると振動数が2倍になることを確かめ、④気柱では、閉管と開管で現れる固有振動のちがいを比べます。気柱共鳴管の実験で、共鳴が起こる長さを予想するときにも使えます。
  • まとめ：弦・閉管・開管の「端のようす」と固有振動数の式を表にまとめます。ギターの弦を押さえると音が高くなる理由や、管楽器の音の高さとも結びつけられます。

生徒への問いの例：

  1. 440 Hz のおんさと、振動数がわからないおんさを同時に鳴らすと、1秒間に3回うなりました。もう一方のおんさの振動数は何 Hz でしょう。どちらか1つに決めるには、どうすればよいでしょう。
  2. 弦の張力を4倍にすると、基本振動の振動数は何倍になるでしょう。弦の長さを半分にしたときはどうでしょう。
  3. 同じ長さの閉管と開管では、どちらの基本振動数が高いでしょう。閉管に2倍振動が現れないのはなぜでしょう。

しくみ・解説

用語の意味

  • 波の重ね合わせの原理とは、2つの波が重なった点の変位は、それぞれの波の変位の和になるという原理です。
  • うなりとは、振動数がわずかに異なる2つの音が重なったとき、音の大きさが周期的に大きくなったり小さくなったりする現象です。
  • 定常波（定在波）とは、振幅・波長・振動数が等しく、互いに逆向きに進む2つの波が重なってできる、どちらにも進まない波です。
  • 節とは定常波でまったく振動しない点で、腹とは最も大きく振動する点です。
  • 固有振動とは、弦や気柱が、両端の条件で決まる定常波をつくって振動することで、その振動数を固有振動数といいます。いちばん低い固有振動を基本振動、その n 倍の振動数のものを n 倍振動といいます。
  • 共鳴（共振）とは、外から加わる振動の振動数が物体の固有振動数と一致したとき、物体が大きく振動する現象です。
  • 開口端補正とは、気柱の開いた端の腹が管口より少し外側にできるときの、そのずれの長さ Δx です。

うなりの回数

うなりの回数（1秒あたり） f＝|f₁−f₂|　　うなりの周期 T＝1/|f₁−f₂|

振幅の等しい2つの音 y₁＝A sin 2πf₁t、y₂＝A sin 2πf₂t を重ねると、y＝2A cos{π(f₁−f₂)t}・sin{π(f₁＋f₂)t} となります。聞こえる音の高さは、ほぼ2つの平均の振動数 (f₁＋f₂)/2 で、振幅（音の大きさ）が 2A|cos{π(f₁−f₂)t}| にしたがって変化します。この大きさの山は1秒間に |f₁−f₂| 回やってきます。

計算例：440 Hz と 443 Hz の音を重ねると、うなりは |440−443|＝3 回/秒、うなりの周期は 1÷3≒0.33 秒です。振動数がわからないおんさとのうなりが3回/秒なら、そのおんさは 437 Hz か 443 Hz です。わからない方のおんさに小さなおもりを付けると振動数が少し下がるので、うなりが減れば 443 Hz、増えれば 437 Hz と決められます。

定常波（定在波）

y₁＝A sin 2π(t/T − x/λ)（右へ進む）、y₂＝A sin 2π(t/T ＋ x/λ)（左へ進む）
y＝y₁＋y₂＝2A cos(2πx/λ)・sin(2πt/T)　→　隣り合う節の間隔＝λ/2、腹と節の間隔＝λ/4

合成波は、場所によって振幅 2A|cos(2πx/λ)| が決まり、どの点も同じ周期でその場で振動するだけで、波形は左右に進みません。反射でできる定常波では、固定端は節、自由端は腹になります。

計算例：波長 λ＝40 cm の波が固定端で反射してできる定常波では、節は端から 0 cm、20 cm、40 cm、…の位置、腹は端から 10 cm、30 cm、…の位置にできます。

弦の固有振動

弦を伝わる波の速さ v＝√(S/ρ)（S：張力〔N〕、ρ：線密度〔kg/m〕）
n 倍振動の波長 λₙ＝2L/n　　固有振動数 fₙ＝v/λₙ＝nv/2L（n＝1, 2, 3, …）

両端が固定された弦では、両端が節になる定常波だけが続きます。長さ L の中に半波長（λ/2）がちょうど n 個入るので λₙ＝2L/n です。

計算例：長さ L＝0.50 m、張力 S＝40 N、線密度 ρ＝1.0 g/m＝1.0×10⁻³ kg/m の弦では、v＝√(40÷0.0010)＝200 m/s、基本振動数 f₁＝200÷(2×0.50)＝200 Hz、2倍振動 400 Hz、3倍振動 600 Hz です（このシミュレーションの初期設定）。張力を4倍にすると v も f も2倍、線密度を4倍にすると1/2倍、長さを半分にすると f は2倍になります。

気柱の固有振動（閉管・開管）

音速 V＝331.5＋0.6t 〔m/s〕（t：セルシウス温度〔℃〕）
閉管：λ＝4L/(2n−1)、f＝(2n−1)V/4L（基本振動の奇数倍だけ）
開管：λ＝2L/n、f＝nV/2L（基本振動の整数倍すべて）
振動するもの端のようす（変位）波長固有振動数現れる振動
弦（両端を固定）両端が節λₙ＝2L/nfₙ＝nv/2L（v＝√(S/ρ)）基本振動の整数倍すべて（1, 2, 3, …倍）
閉管（片方が閉じた管）閉じた端が節、開いた端が腹λ＝4L/(2n−1)f＝(2n−1)V/4L奇数倍だけ（1, 3, 5, …倍）
開管（両方が開いた管）両端が腹λ＝2L/nf＝nV/2L整数倍すべて（1, 2, 3, …倍）

閉じた端では空気が動けないので変位の節、開いた端では空気が自由に動けるので変位の腹になります。閉管では長さ L の中に λ/4 の奇数倍しか入らないため、基本振動の偶数倍の振動は現れません。なお、変位の節の位置では空気が押し縮められたり引きのばされたりするので、密度（圧力）の変化はいちばん大きくなります。

気柱共鳴管の実験と開口端補正（発展）

気柱共鳴管の口に 440 Hz のおんさを近づけ、水面を下げていくと、1回目に L₁＝18.6 cm、2回目に L₂＝57.6 cm で共鳴したとします。共鳴が起こる長さの差は半波長なので、λ/2＝57.6−18.6＝39.0 cm、λ＝78.0 cm、音速は V＝fλ＝440×0.780＝343 m/s と求められます。また、1回目の共鳴では L₁＋Δx＝λ/4 なので、開口端補正は Δx＝19.5−18.6＝0.9 cm です。開口端補正の大きさは、管の半径の0.6倍ほどになることが知られています。このシミュレーションで「開口端補正を考える」を選ぶと、半径 2 cm の管として Δx＝1.2 cm を加えて計算します（閉管は L＋Δx、開管は L＋2Δx）。

このシミュレーションで単純にしていること

  • 音はすべて正弦波（純音）としています。実際の楽器の音は、基本振動に倍振動が混ざった音です。
  • 定常波・弦・気柱の動きは、目で追えるように実際よりゆっくり表示しています。気柱の空気の粒の動きは、大きく誇張しています。
  • 弦の波の速さの式 v＝√(S/ρ) は、教科書によっては発展として扱われたり、問題文で与えられたりします。
  • 音は Web Audio の機能で、端末の中だけで作って鳴らしています（外部との通信はありません）。スピーカーの性能によって、低い音や高い音は聞こえにくいことがあります。

よくある質問

うなりの回数は、どうやって求めますか？
2つの音の振動数の差の大きさ |f₁−f₂| が、1秒あたりのうなりの回数です。例えば 440 Hz と 443 Hz なら、1秒間に3回うなります。うなりの周期（音が大きくなってから次に大きくなるまでの時間）は 1/|f₁−f₂| 秒で、この例では約0.33秒です。
定常波（定在波）の節と節の間隔は？
隣り合う節と節の間隔は半波長 λ/2、隣り合う腹と節の間隔は λ/4 です。固定端で反射してできる定常波では端が節に、自由端で反射してできる定常波では端が腹になります。
閉管で偶数倍の振動が現れないのはなぜですか？
閉管では、閉じた端が変位の節、開いた端が変位の腹になります。長さ L の中に λ/4 の奇数倍（λ/4、3λ/4、5λ/4、…）しか入らないので、固有振動数は基本振動数 V/4L の奇数倍（1倍、3倍、5倍、…）だけになります。
開口端補正とは何ですか？
気柱の開いた端にできる腹が、実際には管口より少し外側にできることを考えに入れたときの、そのずれの長さ Δx のことです。管の半径のおよそ0.6倍で、気柱共鳴管の実験では、1回目と2回目に共鳴する長さの差（＝λ/2）を使うと Δx の影響を消して波長を求められます。
弦の振動数を高くするには、どうすればよいですか？
弦の固有振動数は fₙ＝(n/2L)√(S/ρ) なので、弦を短くする、張力を大きくする、線密度の小さい（細い・軽い）弦にする、のいずれかで高くなります。張力を4倍にすると振動数は2倍になります。
音速の式 V＝331.5＋0.6t の t は何ですか？
気温（セルシウス温度、単位は℃）です。0℃で 331.5 m/s、気温が1℃上がるごとに約 0.6 m/s 速くなり、20℃では 343.5 m/s です。
