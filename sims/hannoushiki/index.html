このシミュレーションでわかること

化学反応式は、化学変化を化学式と係数で表したものです。化学変化の前後で、原子の種類と数は変わりません（原子が組み替わるだけ）。そのため、矢印（→）の左右で原子の数が等しくなるように、化学式の前に係数をつけます。このシミュレーターでは、原子をつぶ（モデル）で表し、係数を変えると分子のつぶが増えたり減ったりします。左右の数がそろったところで「反応させる」を押すと、原子が組み替わって反応後の物質になるようすをアニメーションで確かめられます。

対応する単元：中学校 第1分野（4）化学変化と原子・分子「化学変化」（中学2年：化学変化を原子や分子のモデルで説明し、化学反応式で表すこと）。分解・酸化と還元・化学変化と熱・中和（中学3年）の反応も問題に入れています。

授業での使い方

導入：原子はなくなる？ 増える？

第1問（水の生成）をすべて係数1のまま「反応させる」を押させると、O が1個あまって赤くふるえます。「化学変化で原子が消えることはあるかな？」と問い、原子の数をそろえる必要があることに気付かせます。

展開：係数のつけ方を練習する

マグネシウムの燃焼・銅の酸化・酸化銀の分解と進め、「ふくまれる原子の種類が少ない式から」「単体（O₂・H₂ など）は最後に」というコツを見つけさせます。原子の数の表示（左○個・右○個）が全部 ✓ になると「反応させる」ボタンが光ります。

まとめ：モデルと式を行き来する

正解すると、式とその反応の説明が出ます。ノートに式を写し、同じ反応をつぶのモデルの図でもかかせると、係数（分子の数）と化学式の右下の小さい数（分子の中の原子の数）の違いが定着します。

生徒への問いの例

  • 2H₂O の「2」と、H₂O の「₂」は、それぞれ何の数を表していますか？
  • H₂ + O₂ → H₂O₂ とすると原子の数はそろいますが、なぜ正しくないのでしょう？（H₂O₂ は水ではない別の物質）
  • 係数を全部2倍した式（4H₂ + 2O₂ → 4H₂O）は、なぜ答えにしないのでしょう？

しくみ・解説

化学反応式のつくり方（3ステップ）

  1. 反応前の物質を左に、反応後の物質を右に、ことばの式で書く（例：水素 ＋ 酸素 → 水）。
  2. それぞれを化学式にする（H₂ ＋ O₂ → H₂O）。化学式の右下の数は変えてはいけません（変えると別の物質になる）。
  3. 左右で原子の数が等しくなるように、化学式の前に係数をつける（2H₂ ＋ O₂ → 2H₂O）。係数はいちばん簡単な整数の比にし、1は書きません。
ポイント：係数は「分子（または物質の単位）が何個か」、化学式の右下の数は「その中に原子が何個か」。2H₂O の H の数は 2×2＝4個です。

よくある質問

化学反応式の係数はどうやって決めますか？
左右で原子の数が等しくなるように決めます。①ふくまれる物質の少ない原子（1か所にしか出てこない原子）からそろえる、②O₂ や H₂ などの単体は最後に合わせる、③最後に全部の係数を同じ数でわれないか確かめて、いちばん簡単な整数の比にする、の順に進めると解きやすくなります。
係数と化学式の右下の小さい数のちがいは何ですか？
係数（式の前の大きい数）は、その分子（物質の単位）が何個あるかを表します。化学式の右下の小さい数は、1個の分子の中にその原子が何個あるかを表します。2H₂O は「H₂O が2個」で、H は2×2＝4個、O は2個です。
なぜ化学式の右下の数を変えて数をそろえてはいけないのですか？
右下の数を変えると、別の物質になってしまうからです。たとえば H₂O の O を2にすると H₂O₂（過酸化水素）という別の物質になります。数をそろえるときは、係数だけを変えます。
係数が1のときはどう書きますか？
1は書きません。たとえば炭素の燃焼は 1C + 1O₂ → 1CO₂ ではなく、C + O₂ → CO₂ と書きます。
4H₂ + 2O₂ → 4H₂O は間違いですか？
原子の数はそろっていますが、化学反応式では係数をいちばん簡単な整数の比にするきまりがあるので、全部を2でわって 2H₂ + O₂ → 2H₂O と書きます。
水の電気分解で水素と酸素が2：1の体積で出るのはなぜですか？
化学反応式 2H₂O → 2H₂ + O₂ のとおり、水素分子が2個できるとき酸素分子は1個できるからです。同じ温度・圧力の気体は、分子の数が同じなら体積も同じなので、体積の比も2：1になります。
