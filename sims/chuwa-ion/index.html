酸・アルカリと中和のシミュレーター（BTB溶液の色とイオンのモデル）

うすい塩酸（BTB溶液入り）に、こまごめピペットで水酸化ナトリウム水溶液を1 cm³ずつ加えると、液の色が黄色→緑色→青色と変わります。ビーカーの中のイオン（H⁺・Cl⁻・Na⁺・OH⁻）の数と、加えた量とイオンの数のグラフ、pH（参考）を同時に確かめられます。小6向けに、身近な水溶液をリトマス紙で仲間分けするモードもあります。

中3：左＝ビーカーの中のイオンのモデル（赤 H⁺ 水素イオン、緑 Cl⁻ 塩化物イオン、紫 Na⁺ ナトリウムイオン、青 OH⁻ 水酸化物イオン、水色 水の分子）。ビーカーをタップしても1 cm³ずつ加えられます。右上＝加えた量とイオンの数のグラフ、右下＝液の性質・pH（参考）と指示薬の色。小6：水溶液をタップすると、選んだ調べ方で調べ、下の箱に仲間分けされます。

このシミュレーションでわかること

うすい塩酸にBTB溶液を入れ、水酸化ナトリウム水溶液を少しずつ加えると、液の色は黄色（酸性）→緑色（中性）→青色（アルカリ性）と変わります。このとき液の中では、酸性のもとである水素イオン（H⁺）と、アルカリ性のもとである水酸化物イオン（OH⁻）が結びついて水（H₂O）ができ、たがいの性質を打ち消し合っています（中和）。残ったナトリウムイオン（Na⁺）と塩化物イオン（Cl⁻）は、塩（塩化ナトリウム）として液にとけています。イオンの数の変化を、モデル図と4本の折れ線グラフで同時に確かめられます。

対応する単元：中学3年 第1分野（6）化学変化とイオン ア（ア）水溶液とイオン「㋑酸・アルカリ」「㋒中和と塩」（内容の取扱いで、酸・アルカリでは pH にも触れることとされています）／小学6年 A（2）水溶液の性質「水溶液には，酸性，アルカリ性及び中性のものがあること」（リトマス紙などを用いた仲間分け）。実験の切りかえ（上のメニュー）で「小6 水溶液の仲間分け」を選ぶと、塩酸・炭酸水・食塩水・石灰水・アンモニア水・水酸化ナトリウム水溶液をリトマス紙・BTB溶液・蒸発で調べられます。

授業での使い方

導入：混ぜると性質はどうなる？（中3）

「塩酸（酸性）に水酸化ナトリウム水溶液（アルカリ性）を加えていくと、液の性質はどうなるか」を予想させてから、「💧 1 cm³ 加える」を押していきます（ビーカーをタップしても加えられます）。BTB溶液の色が黄色のまましばらく変わらず、10 cm³ でちょうど緑色、そのあと青色になることを確かめます。

展開：イオンの数をグラフにする（中3）

1 cm³ ずつ加えるたびに、左のモデル図で OH⁻ が H⁺ と結びついて水になる様子と、右のグラフで4種類のイオンの数の変化を見ます。H⁺ は減って中性で0になり、OH⁻ は中性までは0で、そのあと増えます。Na⁺ は加えた量に比例して増え、Cl⁻ はずっと変わりません。「水酸化ナトリウム水溶液の濃さ」を2倍にすると、中性になるのが 5 cm³ になることも確かめられます。「🎨 指示薬」ボタンでフェノールフタレイン溶液に切りかえると、アルカリ性になったときだけ赤色に変わる（酸性・中性では無色）ことも比べられます。

導入・まとめ：水溶液の仲間分け（小6）

「小6 水溶液の仲間分け」に切りかえ、見た目はどれも無色とうめいな6つの水溶液を、リトマス紙で1つずつ調べて、酸性・中性・アルカリ性に分けます。「調べ方」を「蒸発させる」にすると、何も残らない水溶液（気体がとけている）と、白い固体が残る水溶液（固体がとけている）に分かれます。中3では、この仲間分けをふり返ってからイオンの学習に入ると、つながりがはっきりします。

児童・生徒への問いの例

  1. 塩酸に水酸化ナトリウム水溶液を6 cm³ 加えた。BTB溶液は黄色のままなのに、中和は起きているといえるだろうか？（モデル図で H⁺ の数を数えてみよう）
  2. 中性になった液を蒸発させると、白い結晶が残った。この物質は何だろう？それはどのイオンとどのイオンからできたのだろう？
  3. リトマス紙で調べると、炭酸水は酸性、食塩水は中性、石灰水はアルカリ性だった。炭酸水を蒸発させても何も残らないのはなぜだろう？

しくみ・解説

用語の意味（1文で）

  • 酸とは、水溶液にしたときに電離して水素イオン（H⁺）を生じる物質です（例：塩化水素 HCl → H⁺ ＋ Cl⁻）。
  • アルカリとは、水溶液にしたときに電離して水酸化物イオン（OH⁻）を生じる物質です（例：水酸化ナトリウム NaOH → Na⁺ ＋ OH⁻）。
  • 中和とは、酸の水溶液とアルカリの水溶液を混ぜたとき、H⁺ と OH⁻ が結びついて水ができ、たがいの性質を打ち消し合う反応です（H⁺ ＋ OH⁻ → H₂O）。
  • 塩（えん）とは、中和のときに、酸の陰イオンとアルカリの陽イオンが結びついてできる物質です（例：塩化ナトリウム NaCl）。
  • pH（ピーエイチ）とは、酸性・アルカリ性の強さを0〜14の数値で表したもので、7が中性、7より小さいほど酸性が強く、7より大きいほどアルカリ性が強いことを表します。
  • 指示薬とは、液の性質によって色が変わる薬品で、リトマス紙・BTB溶液・フェノールフタレイン溶液などがあります。
塩酸と水酸化ナトリウム水溶液の中和
HCl ＋ NaOH → NaCl ＋ H₂O（塩化水素＋水酸化ナトリウム → 塩化ナトリウム＋水）
イオンで書くと：H⁺ ＋ Cl⁻ ＋ Na⁺ ＋ OH⁻ → Na⁺ ＋ Cl⁻ ＋ H₂O

加えた量とイオンの数（モデル）

このシミュレーションでは、うすい塩酸10 cm³ の中の H⁺ と Cl⁻ をそれぞれ10こ、同じ濃さの水酸化ナトリウム水溶液1 cm³ の中の Na⁺ と OH⁻ をそれぞれ1こと考えています（授業で数えやすい小さな数にしたモデルです）。

グラフにすると、教科書によく出る4本の折れ線になります。

  • H⁺（水素イオン）：加えた OH⁻ と結びついて水になるので減り、中性で0になる。そのあとは0のまま。
  • Cl⁻（塩化物イオン）：どの イオンとも結びつかないので、ずっと10こで変わらない。
  • Na⁺（ナトリウムイオン）：どのイオンとも結びつかないので、加えた量に比例して増え続ける。
  • OH⁻（水酸化物イオン）：中性までは H⁺ と結びついて水になるので0。中性をこえると、加えた分だけ増える。

イオンの総数は、中性になるまでは変わらず（H⁺ が1こ減るたびに Na⁺ が1こ増える）、中性をこえると増えていきます。

計算問題の解き方（例題）

例題1　うすい塩酸10 cm³ を中性にするのに、水酸化ナトリウム水溶液が10 cm³ 必要だった。同じ塩酸15 cm³ を中性にするには、水酸化ナトリウム水溶液は何 cm³ 必要か。
中和する体積は比例するので、10×15/10＝15 cm³。

例題2　例題1の水酸化ナトリウム水溶液の濃さを2倍にすると、塩酸10 cm³ を中性にするのに何 cm³ 必要か。
1 cm³ にふくまれる OH⁻ が2倍になるので、必要な体積は半分の 5 cm³（シミュレーションの「濃さ2倍」で確かめられます）。

例題3　H⁺ が10このモデルの塩酸に、OH⁻ が6こ入った水酸化ナトリウム水溶液を加えた。液の中の H⁺、OH⁻、Na⁺、Cl⁻ はそれぞれ何こか。また、できた水の分子は何こか。
OH⁻ 6こはすべて H⁺ と結びつくので、H⁺ 4こ、OH⁻ 0こ、Na⁺ 6こ、Cl⁻ 10こ、水 6こ。H⁺ が残っているので液は酸性です。

pH の値について（参考）

統計欄の pH は、塩酸と水酸化ナトリウム水溶液の濃さをどちらも0.1 mol/L（約0.4％、濃さ2倍は0.2 mol/L）として計算した参考値です。中性の近くで pH が大きくとぶのは、わずかな H⁺ や OH⁻ の残りでも pH が大きく変わるためです（たとえば9 cm³ では pH 2.3、11 cm³ では pH 11.7）。中学校では「pH 7 が中性で、7より小さいほど酸性が強く、7より大きいほどアルカリ性が強い」ことを押さえれば十分です。

塩酸とアンモニア水はつんとしたにおいがあります。においを調べるときは、直接かがずに手であおいでかぎます。蒸発させる実験は、換気をよくして少量で行います。

中和について知っておきたいこと

  • 中性にならなくても中和は起きている：BTB溶液が黄色のままでも、加えた OH⁻ は H⁺ と結びついて水になっています。中和は「中性になること」ではなく「H⁺ と OH⁻ が結びつくこと」です。
  • 水にとける塩ととけない塩：塩酸と水酸化ナトリウム水溶液からできる塩化ナトリウムは水にとけるので、液の中では Na⁺ と Cl⁻ のままです。うすい硫酸と水酸化バリウム水溶液を混ぜると、水にとけにくい塩（硫酸バリウム）ができ、白い沈殿になります。
  • 中和の熱：中和が起きると熱が出て、液の温度が少し上がります。
  • 身の回りの中和：酸性になった土に石灰をまいて中和する（土壌の改良）、胃酸を中和する胃薬、温泉の強い酸性の水を石灰で中和する施設などがあります。

このシミュレーションで単純化していること

  • イオンの数（H⁺・Cl⁻ が各10こ）は数えやすいように決めたモデルで、実際の水溶液にはけた違いに多くのイオンがあります。イオンの大きさ・色・動きも模式的です。
  • 中和で H⁺ と OH⁻ が結びつく動きは、見やすいようにゆっくり描いています。実際の中和は、混ぜたとたんにほぼ一瞬で起こります。
  • 液の色は、BTB溶液では pH 6.0 以下を黄色、7.6 以上を青色、フェノールフタレイン溶液では pH 8.2 以上を赤色としています。水そのものがわずかに電離してできる H⁺ と OH⁻ は、モデル図では省略しています。
  • リトマス紙の仲間分けで示した pH は、市販の炭酸水や、学校の実験でよく使うくらいのうすさの水溶液の目安です。

よくある質問

中和とは何ですか？
酸の水溶液とアルカリの水溶液を混ぜたとき、水素イオン（H⁺）と水酸化物イオン（OH⁻）が結びついて水ができ、たがいの性質を打ち消し合う反応です。塩酸と水酸化ナトリウム水溶液の中和では、水と塩化ナトリウム（塩）ができます。
塩酸に水酸化ナトリウム水溶液を加えると、BTB溶液の色はどう変わりますか？
はじめは酸性なので黄色、ちょうど中和して中性になると緑色、さらに加えてアルカリ性になると青色になります。同じ濃さなら、塩酸10 cm³に水酸化ナトリウム水溶液10 cm³を加えたときに緑色になります。
中性にならないと中和は起きていないのですか？
いいえ。BTB溶液が黄色のままでも、加えたOH⁻はH⁺と結びついて水になっており、中和は起きています。中性になるのは、H⁺とOH⁻が過不足なく結びついたときです。
中和のときのイオンの数のグラフはどうなりますか？
H⁺は減って中性で0になり、そのあと0のままです。OH⁻は中性までは0で、そのあと増えます。Na⁺は加えた量に比例して増え続け、Cl⁻は変わりません。イオンの総数は中性までは一定で、そのあと増えます。
塩（えん）とは何ですか？
中和のときに、酸の陰イオンとアルカリの陽イオンが結びついてできる物質です。塩化ナトリウム（Na⁺とCl⁻）は水にとける塩、硫酸バリウム（うすい硫酸と水酸化バリウム水溶液からできる）は水にとけにくい塩で、白い沈殿になります。
リトマス紙の色はどう変わりますか？
酸性の水溶液は青色リトマス紙を赤色に、アルカリ性の水溶液は赤色リトマス紙を青色に変えます。中性の水溶液では、どちらのリトマス紙も色が変わりません。
