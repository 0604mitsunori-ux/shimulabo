# シミュラボ「図」作成仕様（作成担当向け・2026-10-18）

シミュのページの本文に、**コードで描いた図（SVG）**を入れる。目的は2つ。
1. **授業・資料でそのまま使える**（電子黒板に映す・プリントやスライドに貼る）。ページには「PNGで保存（2400×1350）・SVG」のリンクが自動で付く。
2. **検索（画像検索を含む）とAIに中身を伝える**。alt・キャプション・構造化データの image が自動で付く。

画像生成AIは使わない。**シミュと同じ式・同じデータから描く**ので、図とシミュが必ず一致する。

## 1. 作るもの
- `scripts/figs/<slug の - を _ にした名前>.py`（例：`tsuki-michikake` → `tsuki_michikake.py`）に `FIGS = [dict(...), ...]` を書く。
- **お手本**：`scripts/figs/tsuki_michikake.py`（しくみ図＋時刻・方角の早見）と `scripts/figs/totsu_lens.py`（作図＋早見表）。まずこの2つと、できあがりの PNG（`sims/tsuki-michikake/tsuki-michikake-1.png` など）を見る。
- 部品：`scripts/figs/figlib.py`（`svg()` 枠・`text/lines/line/arrow/poly/rect/circle/badge/table/axes/moon_look`・色の名前）。`from figlib import *` で使う。**figlib.py は書き換えない**（足りない部品は自分のモジュールの中に関数で書く）。

### dict のキー
| キー | 内容 |
|---|---|
| svg | SVG 文字列を返す関数（`figlib.svg(本文, 見出し, 下の一言)` で包む）。1200×675 固定 |
| alt | 何が描いてあるかを1〜2文で具体的に（例「〜を示す図」「〜の早見表」）。ページの主なキーワードを自然に含める |
| caption | 図の下に出る1文（例「作図のしかた。3本の光のうち2本で像の位置が決まる。」） |

モジュールに `ANCHOR = r"正規表現"` を書くと、その文字列の直後に図が入る（省略時：「しくみ」を含む見出しの直後 → なければ本文の最初の見出しと直後の段落の後）。理科ページは省略でよい。

### 枚数と中身
- **理科の授業向けページ：2枚**。
  - 図1＝**しくみ図**（目に見えないもの・全体の関係を1枚で。例：月と太陽と地球の位置、回路の電流の流れ、体の中の血液の流れ）
  - 図2＝**まとめ図**（板書やプリントに貼る形。早見表・条件をそろえた比較・作図の手順・グラフの読み方・覚えるポイントのまとめ）
- **一般ページ：1〜2枚**。計算のしくみ（式を図で）・早見表・比較のどれか。ページの結果をそのまま図にするのでなく、「読む人が知りたい答えの全体像」を1枚で。

## 2. デザインの決まり
- 1200×675（16:9）。本文は y=100〜620 の中に描く（見出し・下の一言・サイト名は `svg()` が描く）。
- 文字は **14px 以上**（本文 16〜18px・大事な数値 20px 以上）。電子黒板で後ろの席から読める大きさ。
- 色は figlib の名前を使う（墨 INK・藍 TEAL・朱 ACC・金 GOLD など）。**赤と緑だけで区別しない**（ラベルや形でも区別する）。
- 写真風・装飾過多にしない。教科書の図のように、線・矢印・ラベルで。余白を十分に。
- 日本語のラベル。単位は教科書の書き方（cm、g、N、℃、%）。
- 大きさ・距離を誇張した模式図は、図の中に「（大きさ・きょりは実際とちがう）」のように一言書く。

## 3. 正確さ（いちばん大事）
- 数値・形・向きは、**そのページのシミュの JS／生成モジュール（scripts/rika/sims_*.py や scripts/gen_sims*.py）と同じ式で計算**して描く。手で数字を書くときは、Python で別に計算して照合する。
- 教科書の決まり（例：凸レンズの作図はレンズの中心の線で1回曲げる、顕性・潜性、震度階級の名前）に合わせる。理科は `C:\Users\社員\Desktop\Nsawa\プロジェクト\シミュラボ_理科授業\学習指導要領テキスト\` を grep して言い方を確かめる。
- 失敗例：月の早見表で三日月が南中する時刻を「昼の9時ごろ」と書いた（正しくは午後3時ごろ＝新月の正午から1日約50分ずつ遅れる）。**時刻・方角・向き・順番は必ず計算か一次資料で確かめる。**
- 小学生向けのページは、その学年が読める言葉で（難しい漢字はひらがなに）。

## 4. 確認手順（必ず全部）
1. `python scripts/build_figs.py --only <slug>[,<slug>…]` → `sims/<slug>/<slug>-<n>.svg/.png` ができ、ページに差し込まれる。
2. **できた PNG を Read で全部開いて自分の目で見る**：文字の重なり・はみ出し・切れ、矢印の向き、数値の正しさ。直したらもう一度1から。
3. `grep -c "rika-figs:start" sims/<slug>/index.html` が 1 であること。
4. 主要な数値を別計算で照合（報告に書く）。

## 5. 触ってはいけないもの
`scripts/figs/figlib.py`・`scripts/build_figs.py`・他の担当の figs モジュール・`scripts/rika/` の中身・`index.html` など全体のファイル。**ページの HTML を手で編集しない**（差し込みは build_figs.py がやる）。git の commit / push はしない。ブラウザの共有ペイン（Claude_Browser）は使わない。書いてよいのは自分の担当の `scripts/figs/<名前>.py` と、build_figs.py が作る `sims/<slug>/` の図ファイル・index.html だけ。
